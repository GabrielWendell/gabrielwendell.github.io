A light curve, an electrocardiogram, and a vibration signal can all be stored as an ordered sequence of measurements. They can also be drawn as images. This creates a tempting question: if a convolutional neural network can recognize patterns in an image, should we turn every time series into a picture before classifying it?

A 1D CNN slides filters along the numerical sequence. A 2D CNN slides filters across a raster representation of that sequence. Both can recognize curve morphology, but they encode different assumptions about which patterns should be easy to learn.

The useful comparison combines three things: what information reaches the classifier, how much computation the chosen architecture performs, and how well a trained model generalizes. We can prove statements about the first two and measure parts of the third. Keeping their logical roles clear prevents a fast implementation from being mistaken for an accuracy theorem.

The calculations below culminate in two synthetic classification experiments, an exact numerical equivalence check, and a rasterization counterexample. The complete Python code, raw results, and original figures accompany this post.

What does “more efficient” mean?

There are several reasonable objectives, and they need not favor the same model.

Objective Quantity to compare
Classification quality Error, macro-F1, or another task-appropriate metric on unseen series
Statistical efficiency Number of independent labeled series needed for a target error
Inference efficiency Arithmetic, latency, throughput, and memory per prediction
Training efficiency Total cost of reaching a target validation quality
Representation efficiency Cost and fidelity of preprocessing, storage, and transfer

In particular, equal epoch counts do not imply equal computation. Equal parameter counts do not imply equal arithmetic. Equal information in the inputs does not imply that two restricted CNNs can express the same decision rules.

This post studies ordinary dense convolutions on numerical samples and controlled pixel plots. A spectrogram, recurrence plot, or wavelet map is a different representation with a different geometric structure; conclusions about ordinary curve plots should not automatically be transferred to those encodings.

Empirically, ordinary line-plot CNNs have been competitive on some time-series datasets: Rodrigues and collaborators investigated this directly [2]. The numerical experiment

The experiments use two balanced binary tasks, each with samples per series.

Oscillations. The observations follow on . Class 0 has cycles per window; class 1 has . Independently, , , , and .

Transients. Class 0 contains one Gaussian peak of width 0.06. Class 1 contains two peaks of width 0.025, displaced by from a shared center. The center is uniform in and the signal amplitude in . Both classes include a sinusoidal background of amplitude 0.1, a random offset in , and independent Gaussian noise of standard deviation 0.06. The script gives the full generator.

For each task, independent generation seeds produce 512 training, 128 validation, and 512 test series, balanced within each split. No generated observation exceeds ; the script aborts rather than silently clipping if that condition fails. Both models receive the same 32-level quantization. The data splits are fixed across three training seeds: 42, 43, and 44.

Each network has three convolution–ReLU–max-pooling blocks with 8, 16, and 24 channels. The 1D kernels have width 5; the 2D kernels have shape . Pooling halves the temporal dimension in both models and the vertical dimension in the image model. Global average pooling feeds a two-class linear head. There is no pretraining, normalization layer, dropout, or hyperparameter search.

Both use Adam with learning rate 0.003, batch size 64, and 25 epochs. The checkpoint with minimum validation cross-entropy is evaluated once on the test split. Training configurations are run in a reproducibly shuffled order. The procedure deliberately matches channel counts and training updates, not parameter count or computational budget. It is a controlled illustration, not an architecture-selection contest.

Both models reached perfect observed test accuracy on oscillations under this recipe. On transients, all three 1D runs reached 100%, while the 2D runs reached 100%, 91.60%, and 50%. The validation histories show substantial optimization variability in the image model:

Figure 5. Individual validation trajectories. The chance-level image run remains near 50% through the allocated training budget. Other image runs learn the same task, demonstrating why a failed optimization run cannot establish an information-theoretic limitation.

The selected checkpoint was epoch 25 in every run. The experiment shows that the numerical architecture was faster and more reliable under these particular settings. It does not show that every 2D CNN is worse on transients, or that the learning rate and width choices were equally suitable for both architectures.

The timing and accuracy comparisons answer different questions. A checkpoint selected from 25 equal-budget epochs describes one training procedure. A comparison of the cheapest models reaching the same accuracy would need an additional search over architectures and optimization settings, with the search costs recorded.

In the experiments above, sampling is independent conditional on the fixed class labels, and equal class counts target the equal-prior risk; the corresponding Hoeffding argument applies to those independent class-conditional errors. Multiple seeds share test objects, so their test errors should not be treated as additional independent test samples.

A confidence interval for a trained classifier still does not bound the optimal error of its entire architecture family. This is why benchmark outcomes and analytical lower bounds should be presented as different kinds of evidence.

Reproducing and extending the comparison

The companion files contain experiments.py, build_figures.py, raw JSON and CSV results, per-seed predictions, and the original SVG and PNG figures. On a compatible Python environment, the CPU reproduction commands are:

python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python experiments.py --epochs 25 --threads 2 --seeds 42 43 44
python build_figures.py
python build_post.py

The package records the tested dependency versions. Other hardware or library versions may change timings and floating-point training trajectories. The mathematical decoder identity and arithmetic counts do not depend on a particular runtime measurement.

The central encoder is short enough to inspect directly:

step = (high - low) / height
codes = np.floor((x - low) / step).astype(np.int64)
quantized = low + (codes + 0.5) * step
image = np.zeros((len(x), 1, height, x.shape[-1]), np.float32)
image[np.arange(len(x))[:, None], 0, codes,
      np.arange(x.shape[-1])[None, :]] = 1.0

Here the inputs must already be within the fixed range. The full implementation validates the generated data and handles index bounds explicitly.

For a broader study, the next experiments would compare equal-parameter and equal-computation budgets, repeat independently generated datasets, and sweep learning rate, width, and image resolution using validation data. Pretrained image models would constitute an additional regime because external training data change the comparison. Strong temporal baselines such as InceptionTime should also be included before making a practical architecture recommendation [6].

Astronomical light curves add another requirement: preserving observation times, uncertainties, and missingness consistently. Feeding only flux values to a standard 1D CNN while a plot encodes irregular timestamps creates an information mismatch. Likewise, normalizing each curve independently can remove an amplitude or offset that the scientific classification depends on.

In this controlled experiment, numerical convolution avoids substantial image-processing work while retaining the same quantized observations. The general mathematical result is narrower: the specified dense architectures have calculable resource ratios, reversible encodings preserve optimal classification error, and lossy rendering can impose an irreducible floor. Whether a different image representation earns back its cost through a better learning bias remains a task-specific question that can be tested with the same discipline.
